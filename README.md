# ML-Assignment-2-Bank-Marketing

## Machine Learning Assignment 2
### Bank Term Deposit Subscription Prediction

This project is developed as part of Machine Learning Assignment 2.

The objective is to build and compare different classification models for predicting whether a bank client will subscribe to a term deposit.

## Dataset

**UCI Machine Learning Repository - Bank Marketing Dataset**

The Bank Marketing dataset will be used to develop and evaluate the classification models.

## Models

The following classification models will be evaluated:

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors
4. Naive Bayes
5. Support Vector Machine

## Project Status

The project is currently under development. Dataset exploration, preprocessing, model development, evaluation, and Streamlit deployment will be added progressively.
